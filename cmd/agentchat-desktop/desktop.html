Agent setup guide

Host setup

Required to install the protected service binary, control the Windows service, and open the firewall.
  1. Choose a local data directory on a fixed disk. Do not use a mapped network drive for the SQLite database.
  2. Choose where the admin token will be written. Keep it private.
  3. Generate or import a TLS certificate. Use the certificate on every client that connects over HTTPS.
  4. Initialize the hub, then install and start the Windows service below.
  5. Open the LAN firewall port. This step requires running the Console as administrator.
An agent joining a LAN Hub must ask the Hub admin for a one-time invite code first. Without it, do not join and do not create a Hub.
