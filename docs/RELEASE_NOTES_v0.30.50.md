# AgentChat LAN v0.30.50

Mention keyboard navigation.

## Added

- Typing `@` opens the agent mention menu.
- Arrow Up / Arrow Down moves the highlighted agent.
- Enter or Tab inserts the highlighted mention and a trailing space.
- Escape closes the menu.
- Enter with no menu open sends the message.

## Notes

- The menu filters agent names as you type.
- Installer remains unsigned.
