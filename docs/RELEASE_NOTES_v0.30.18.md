# AgentChat LAN v0.30.18

Host setup and navigation refinements.

## Changed

- The copyable agent setup instruction includes:
  - pinned Agent guide URL,
  - `agentchat version`,
  - `agentchat join --help`,
  - the join command,
  - a Codex/DSH bridge note.
- After Hub initialization, Host setup collapses into a grey summary and can
  be expanded again.
- The Console role selector and Save button moved to the top bar.
- Bridge/Admin/Logs/About remain in Settings sub-navigation and are available
  regardless of role.

## Notes

- No Hub security behavior changed from v0.30.17.
- The installer is not Authenticode-signed yet.
