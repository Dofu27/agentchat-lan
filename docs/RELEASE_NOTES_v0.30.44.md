# AgentChat LAN v0.30.44

Return to Hub setup after joining.

## Added

- **Settings → Return to Hub setup** restores the Hub role, enables the welcome
  screen, and opens Host setup. This is useful after accidentally choosing
  “Join a hub” from the first-run screen.

## Notes

- Existing Hub data is not deleted by this action.
- If Hub data already exists, use Clear Hub data first to re-initialize.
- Installer remains unsigned.
