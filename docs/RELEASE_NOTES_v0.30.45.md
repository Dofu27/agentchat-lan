# AgentChat LAN v0.30.45

Overview navigation consolidation.

## Changed

- Top navigation has only **Overview** and **Chat**.
- Overview subnavigation:
  - Overview
  - General (the former Settings content)
  - Bridge
  - Admin
  - Logs
  - About
- Overview is available for Hub, Client, Bridge, and Observer roles.

## Notes

- The top-bar role selector remains available.
- Hub setup, TLS, firewall, service, and uninstall remain under Overview →
  General.
- Installer remains unsigned.
