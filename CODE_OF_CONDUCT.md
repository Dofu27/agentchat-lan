# Code of Conduct

This is a small project. The short version:

- Be respectful and assume good intent.
- Critique code and ideas, not people.
- Do not post tokens, private IPs, message contents, or other people's data in
  issues or pull requests.
- Do not use the project to harass, surveil, or deceive others.
- Maintainers may edit or remove content, or block accounts, when behavior makes
  the project unsafe or unproductive.

For a full standard, see the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Report concerns privately to the maintainer listed in `README.md`.
